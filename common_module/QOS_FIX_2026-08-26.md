# QoS Resolution Fix — 2026-08-26

## Problem

SLURM job submissions were being rejected because the wrong QoS was selected. Different partitions restrict which QoS values are allowed (e.g., `compute` allows `default,medium,high` while `preempt` allows only `preempt`). The original code had no QoS handling at all.

Additionally, SLURM 25.x (used on the HPC cluster) broke two assumptions:
1. `scontrol show qos` was removed entirely → returns `invalid entity:qos for keyword:show`
2. Partition field changed from `AllowedQos=` to `AllowQos=` (dropped the 'ed')

## Files Changed

| File | Change |
|------|--------|
| `common_module/query_cluster.sh` | QoS detection + per-partition allowed QoS parsing |
| `common_module/autosubmit.py` | Live QoS query + resolution logic + template injection |
| `common_module/slurm_template.slurm` | Added `\u003c\u003cQOS_LINE\u003e\u003e` placeholder |

## Changes in Detail

### `query_cluster.sh`

#### Global QoS List (lines ~310-345)

**Before:** Single command `scontrol show qos` with regex `grep -oP '^Qos=\K\S+'`

**After:** Three-command fallback chain:
```bash
# 1. sacctmgr show qos format=Name       (SLURM ≥23, preferred)
# 2. sacctmgr -p list qos format=Name    (fallback)
# 3. scontrol show qos                   (legacy SLURM <23)
```

Parser handles:
- Bare names (one per line after header/separator)
- `Qos=name` key=value format (old SLURM)
- `Name=name` inline format (SLURM 25.x: `QoSId=1 Name=default Flags=`)
- Deduplication via `sort -u`

**Key finding:** `override=no` flag is NOT valid on all SLURM 25.x builds — must be omitted.

#### Per-Partition Allowed QoS (lines ~104-120)

Added parsing of `AllowedQos=` AND `AllowQos=` from `scontrol show partition` output:
```bash
if [[ "$line" =~ AllowedQos=(.+)$ ]]; then ... fi    # SLURM <25
if [[ "$line" =~ AllowQos=(.+)$ ]]; then ... fi      # SLURM ≥25
```

Written to `cluster.conf` per partition block:
```ini
  compute:
    allowed_qos = default,medium,high

  preempt:
    allowed_qos = preempt
```

If no restriction detected → writes `allowed_qos = (all)`.

### `autosubmit.py`

#### New `run_cmd()` Helper (line ~62)

```python
def run_cmd(cmd):
    """Run a shell command and return stripped stdout."""
    r = subprocess.run(cmd, shell=True, capture_output=True, text=True, timeout=15)
    return r.stdout.strip()
```

#### Live QoS Query (lines ~250-265)

At submission time, queries SLURM directly:
```python
qos_raw = run_cmd(f"scontrol show partition {partition}")
for m in re.finditer(r"(?:AllowedQos|AllowQos)=(\S+)", qos_raw):
    val = m.group(1)
    if val not in ("(null)", ""):
        part_allowed_qos = [q.strip() for q in val.split(",")]
        break
```

Prints debug info: `[i] Partition 'compute' allows QoS: default, medium, high`

#### Config Fallback (lines ~267-285)

If live query fails, scans `cluster.conf` for the partition block's `allowed_qos` line using regex-based block detection (`^\s{2}\S+:\s*$` for partition headers).

#### QoS Selection Logic (lines ~287-305)

Three-tier resolution:
1. **Per-partition restriction:** Pick first allowed QoS from the partition's list
2. **Global fallback:** Prefer `normal` → `default` → first available from `[qos]` list
3. **No QoS:** Leave empty (SLURM uses its own default)

#### Template Injection (lines ~330-346)

```python
if qos_to_use:
    qos_line = f"#SBATCH --qos={qos_to_use}"
else:
    qos_line = ""
```

Injected via `\u003c\u003cQOS_LINE\u003e\u003e` placeholder.

### `slurm_template.slurm`

Added after account line:
```bash
\u003c\u003cACCOUNT_LINE\u003e\u003e
\u003c\u003cQOS_LINE\u003e\u003e
```

## SLURM Version Compatibility Matrix

| SLURM Version | QoS Query Command | Partition Field | Status |
|--------------|-------------------|-----------------|--------|
| \u003c 23 | `scontrol show qos` (`Qos=name`) | `AllowedQos=` | ✅ Legacy fallback |
| ≥ 23, ≤ 24 | `sacctmgr show qos format=Name` | `AllowedQos=` | ✅ Primary path |
| ≥ 25 | `sacctmgr show qos format=Name` | `AllowQos=` | ✅ Both handled |

## Testing

Tested on the HPC cluster (SLURM 25.11.1) with mock commands simulating:
- `scontrol show qos` → fails with `invalid entity:qos`
- `sacctmgr show qos format=Name` → returns `default medium high normal preempt`
- `scontrol show partition compute` → `AllowQos=default,medium,high`
- `scontrol show partition preempt` → `AllowQos=preempt`

Results:
| Partition | Allowed QoS | Selected QoS |
|-----------|------------|--------------|
| `compute` | `default,medium,high` | `default` ✅ |
| `preempt` | `preempt` | `preempt` ✅ |
| unrestricted + global list | `(all)` | `normal` or `default` ✅ |

## Lessons Learned

1. **Never trust stale config:** Live-query SLURM at submission time, use config only as fallback
2. **SLURM 25.x breaking changes:** Both command syntax (`scontrol show qos` → `sacctmgr`) and field names (`AllowedQos` → `AllowQos`) changed
3. **`override=no` is not portable:** Omit it from `sacctmgr` commands
4. **Header/separator filtering:** `sacctmgr` output includes `Name` header and `----------` separator that must be skipped
5. **Per-partition QoS matters:** Not all partitions allow all QoS values — must query per-partition restrictions
