# Structure Prediction Module Test Files

This folder contains runnable examples for structure prediction workflows.

Current examples:

- `localcolabfold_test_files/` - LocalColabFold test using a precomputed A3M,
  a local model-parameter cache, and three reduced-MSA settings.
- `af2rave_test_files/` - AF2RAVE feature selection, clustering, and optional
  simulation-box setup for externally generated PDB ensembles.
