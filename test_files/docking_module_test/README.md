# Docking Module Test Files

- `jak2_3lpb_example/`: portable JAK2 `3LPB` redocking example showing receptor
  preparation for chains A and B, DOCK6 setup/docking, Vina setup/docking, and
  successful output ligand poses.

This directory contains small example inputs and YAML configs for smoke-testing
the docking pipelines.

## Contents

- `dock6_test_files/`
  - Example receptor PDB, reference ligand Mol2, and docked ligand Mol2 files
  - `example_chimera_config.yaml` for Chimera receptor preparation
  - `example_dock6_config.yaml` for the DOCK6 docking pipeline
- `dock6_dude_examples/`
  - CDK2 and ABL1 kinase examples based on DUD-E targets
  - Prepared receptor/ligand files plus Chimera and Dock6 configs
  - `README.md` with receptor-fetch commands and redocking notes
- `vina_test_files/`
  - Example receptor structures and a reduced `.pdbqt` ligand set
  - `example_vina_gpu_config.yaml` for Vina-GPU
  - `example_vina_cpu_config.yaml` for Vina CPU
  - `README.md` with Vina-specific test commands

## Singularity on HPC Systems

If you are using the provided Singularity images on an HPC system, load
Singularity or Apptainer before running the pipeline:

```bash
module load singularity
```

Some clusters use a different module name, such as `apptainer` or a versioned
Singularity module. Use your cluster's equivalent command if needed.

## Dock6 Smoke Test

1. Update paths in `dock6_test_files/example_chimera_config.yaml`.
2. Run Chimera preparation:

```bash
python docking_module/dock6_pipeline/chimera_pipeline.py \
  --config test_files/docking_module_test/dock6_test_files/example_chimera_config.yaml
```

3. Update paths in `dock6_test_files/example_dock6_config.yaml`, including the
   `.dms` and `.mol2` files generated by the Chimera step.
4. Run DOCK6:

```bash
python docking_module/dock6_pipeline/dock6_pipeline.py \
  --config test_files/docking_module_test/dock6_test_files/example_dock6_config.yaml
```

Add `--overwrite` if you are reusing an output directory from a previous run.

For DUD-E kinase redocking examples, see:

```bash
less test_files/docking_module_test/dock6_dude_examples/README.md
```

## Vina Smoke Tests

Use the Vina-specific README for interface-residue extraction and Vina-GPU test
commands:

```bash
less test_files/docking_module_test/vina_test_files/README.md
```

For Vina CPU, update `vina_test_files/example_vina_cpu_config.yaml` and run:

```bash
python docking_module/vina_pipeline/vina_cpu_pipeline.py \
  --config test_files/docking_module_test/vina_test_files/example_vina_cpu_config.yaml
```
